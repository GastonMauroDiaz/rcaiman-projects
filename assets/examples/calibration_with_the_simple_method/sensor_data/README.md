# Sensor data

This folder contains sensor TIFF files generated by rcaiman-projects during raw data extraction.

The TIFF files contain raw sensor values extracted from RAW files with LibRaw. They are written without demosaicing, white balance, or image corrections.

For each TIFF in `sensor_data`, rcaiman-projects writes a TSV file with the same basename. The TSV links the sensor image to its source RAW file by basename.

Example:

```text
DSCN6280.tif
DSCN6280.tsv
```

## Tools and metadata sources

- LibRaw: sensor TIFF extraction and raw black-level fields.
- ExifTool: aperture, exposure time, ISO, exposure compensation, capture date/time, and GPS fields when present.

## Extraction contract

- Sidecars are UTF-8 TSV files with a header and one data row.
- Paths are relative to the project and use `/` separators.
- Missing values are left empty.
- `metadata_status` is `ok` or `error`.
- `metadata_error` explains per-image extraction problems.
- Sidecars are generated artifacts and can be regenerated from the RAW files.

## R usage

TSV sidecars can be read from R with `read.delim()`.

## Versions

- Sensor TIFF extraction: LibRaw raw sensor extraction
- Metadata sidecar profile: `sensor_metadata_sidecar_tsv_v1`
- ExifTool profile: `exiftool_g1_short_v1`
- ExifTool version: 13.59
- LibRaw version: 0.22.1-Release
