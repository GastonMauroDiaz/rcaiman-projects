rcaiman-projects 0.1.0 - Windows x64

GETTING STARTED

1. Extract the entire ZIP into a folder where you have write permission.
2. Open rcaiman-projects.exe from the extracted folder.
3. Keep the executable together with all the supplied files and subfolders.

Do not run the application from inside the ZIP or copy the executable alone.
Qt Creator, Qt, MSYS2, and administrator privileges are not needed to run it.
This package is intended for 64-bit Windows 10 and Windows 11.

EXAMPLES AND SCIENTIFIC SCRIPTS

Use Help > Example projects... to create a project from the included example.
The application includes ExifTool for metadata extraction. R and the rcaiman
packages are needed separately when you run the example's scientific scripts;
they are not required simply to open the application.
